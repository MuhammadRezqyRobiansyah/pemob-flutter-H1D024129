## 📌 Deskripsi Tugas 2 (Modul 2)
Repositori ini mengimplementasikan materi pembelajaran dari **Modul 2: Pengenalan dan Desain Framework Flutter**, yang meliputi:
1. **Hello World pada Flutter** (`lib/hello_world.dart`): Struktur dasar StatelessWidget, MaterialApp, Scaffold, AppBar, dan Center Text.
2. **Column Widget** (`lib/column_widget.dart`): Menyusun komponen antarmuka secara vertikal.
3. **Row Widget** (`lib/row_widget.dart`): Menyusun komponen antarmuka secara horizontal.
4. **Form Produk & Navigasi Detail** (`lib/ui/produk_form.dart` & `lib/ui/produk_detail.dart`): Input data barang (Kode Produk, Nama Produk, Harga) dan pemindahan data menuju halaman detail produk melalui `Navigator.push`.
5. **List View Data Produk** (`lib/ui/produk_page.dart`): Menampilkan daftar katalog produk dalam bentuk Card ListTile (Kulkas, Playstation, Radio).
